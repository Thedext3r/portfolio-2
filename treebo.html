1. Executive Summary & Design Vision

Treebo Hotels is one of India's leading budget and boutique hospitality franchisors. The "Treebo Club" ecosystem was created to reward loyal guests through member-exclusive discounts, complimentary upgrades, and priority customer care.

✦ Core Redesign Objectives & Hypothesis

Vision: Elevate the Treebo Club digital experience into a modern, delightful, and high-converting travel platform through clean visual hierarchy, transparent pricing patterns, and cohesive component architecture.

Design Hypothesis: By introducing an intuitive multi-facet filter side panel, an interactive split map with synchronized price pins, inline room amenities, and a non-intrusive sign-in modal, Treebo will cut booking task completion time by ~40% and increase completed bookings by +18% to +24%.

  • Transparency First: 100% upfront pricing disclosure eliminating surprise fee additions at payment.
  • Seamless Spatial Discovery: Interactive split map pairing live listing cards with dynamic price pins.
  • Low Cognitive Load: Zero-click inline amenity tags surfacing AC, Free Wi-Fi, and Breakfast directly on room cards.
  • In-Context Authentication: Non-intrusive modal dialog (60% scrim) preserving user search context with 1-tap Google OAuth.
  • Elevated Loyalty Value: Prominent Treebo Club tier branding and instant discount savings displayed across all touchpoints.

The redesigned booking experience guides travelers effortlessly from initial destination exploration to confirmed reservation:

3. Spatial Search Interactive Split Map Dual-pane view with dynamic price pins synchronized in real time with hotel listing cards. Proximity Match
4. Selection Hotel Details Page Expansive categorized photo gallery, permanent 'Selected' room badge, and 1-click amenities modal. Confidence Build

4. Design System Tokens, Typography & Accessibility

The redesign is powered by an accessible, scalable Figma design system enforcing brand unity and design-to-code fidelity.

Token Name Hex / Value Semantic Application & Role
Primary Brand Teal #0F766E / #14B8A6 Primary CTAs, active navigation items, brand badges, and header accents.
Secondary Accent Blue #0284C7 / #38BDF8 Interactive map markers, location links, and secondary informational tags.
Loyalty Amber Gold #C29748 / #FEF08A Treebo Club membership badges, continue CTA buttons, and savings highlights.
Semantic Status Green/Red #16A34A / #DC2626 Green for 'Selected' room badge & free cancellation; Red for urgency tags & form errors.
Neutral Slate Ramp #0F172A / #334155 / #F8FAFC Slate 900 for headings, Slate 700 for body copy, Slate 50 for clean card backdrops.
  • Display & Headings: Montserrat (Bold 700, SemiBold 600) — Used for prominent editorial headlines, destination cards, and hero titles.
  • Interface Body & UI: Inter (Regular 400, Medium 500, SemiBold 600) — High-legibility sans-serif for UI labels, filter chips, prices, and tabular data.
  • Accessibility (WCAG 2.1 AA): 100% compliant contrast ratios (minimum 4.5:1), 44x44pt touch targets, and visible focus indicators.
